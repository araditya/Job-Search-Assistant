## Quick Reference: API Endpoints

All endpoints are at `/ai` prefix:

| Endpoint | Purpose | Auth |
|----------|---------|------|
| POST /ai/parse-query | Parse natural language | None |
| POST /ai/generate-cover-letter | Generate letter | JWT |
| POST /ai/find-hiring-managers | Find managers | None |
| POST /ai/create-outreach | Create workflow | JWT |
| POST /ai/send-outreach | Record outreach | JWT |
| GET /ai/outreach-history | Get history | JWT |
| GET /ai/cover-letters | List letters | JWT |
| DELETE /ai/cover-letters/<id> | Delete letter | JWT |
